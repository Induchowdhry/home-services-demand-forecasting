# Research Notes — Milestone 1

## 1. Long Short-Term Memory (Hochreiter & Schmidhuber, 1997)
Paper: https://www.bioinf.jku.at/publications/older/2604.pdf
Key takeaway: LSTM introduces gated memory cells designed to learn long-term dependencies.

## 2. PyTorch LSTM documentation
https://pytorch.org/docs/stable/generated/torch.nn.LSTM.html
Key takeaway: PyTorch provides `torch.nn.LSTM` for sequence modelling with configurable input size, hidden size, number of layers, dropout and batch-first inputs.

## 3. LSTM Time Series Forecasting
https://machinelearningmastery.com/lstm-for-time-series-prediction-in-pytorch/
Key takeaway: time-series observations can be converted into supervised sequences for recurrent neural-network forecasting.

These references inform the proposed architecture; they do not provide evidence that the supplied CSV is a demand-forecasting dataset.
